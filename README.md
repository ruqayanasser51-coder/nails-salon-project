# Nail Salon

# Nail Salon Booking Website

## User Stories:

### User(1): Customer
- I want to be able to view all available nail services
- I want to be able to look up the details of a nail service
- I want to be able to book an appointment for a nail service
- I want to be able to choose an available date and time for my appointment
- I want to be able to edit my appointment at any time
- I want to be able to cancel my appointment
- I want to be able to see all my appointments

### User(2): Admin
- I want to be able to add a new nail service
- I want to be able to show the details of a nail service
- I want to be able to edit/delete a nail service
- I want to be able to view all appointments
